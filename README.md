# 剧链 DramaLink · 投资人演示 Demo

AI 时代的广告平台——从脚本到成交的完整链路演示。AI 短剧是 AI 生成内容中变现潜力最大的场景，也是第一站。

**线上地址**：https://xinyuxinsheng.github.io/drama-ads-demo/

## 演示的商业故事（四屏）

1. **封面** — 一句话定位 + 已验证的市场数据
2. **脚本期 · 植入工作台** — AI 通读剧本标注植入位，品牌需求自动匹配（CPS 分佣模式），创作者一键确认
3. **生成期 · 前后对比** — 拖动滑杆对比原片与 AI 植入后画面
4. **变现期 · 观看页** — 片头冠名 + 弹幕引导 + 商品卡直达 + 国别自动转链（美/日/中）

## 替换真实视频

把两个视频文件覆盖到 `assets/`（竖屏 9:16 最佳）：

- `assets/original.mp4` — 原始短剧片段
- `assets/placed.mp4` — AI 植入服装后的片段

再按视频内容改 `js/config.js` 里的三个时间参数：

- `badge` — 片头冠名标注的显示时间段
- `garmentAt` — 服装出现的秒数（商品卡在此弹出）
- `danmaku` — 每条弹幕的出现秒数和文案

页面代码不用动。
