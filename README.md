# Adborn · 投资人演示 Demo

Adborn（adborn.ai）：AI 时代的广告平台——广告与内容一同出生。AI 短剧是 AI 生成内容中变现潜力最大的场景，也是第一站。

**线上地址**：https://xinyuxinsheng.github.io/drama-ads-demo/

## 演示的商业故事（按 AI 短剧行业链路分三阶段）

1. **封面** — 一句话定位 + 已验证的市场数据
2. **剧本开发 · 智能植入规划** — 五步流程：剧方上传脚本 → AI 分析植入点（本集 5 个位、4 大品类）→ 商品匹配（已匹配 / 剧方候选 / 多品牌竞价三种形态）→ 剧方确认整案 → 进入镜头生成
3. **AI 成片 · 无痕植入生成** — 三组"原片 vs 植入后"横屏对比，滚动到视口自动同步播放：人物随身（Sony 耳机+Kånken 背包）、道具特写（扇面广告位：高德→大众点评必吃榜）、场景氛围（茶馆全景）
4. **上线投流 · 全球转链变现** — 横屏播放器：片头植入声明 + 弹幕引导 + 商品卡直达 + 美/日/中国别自动转链

## 改卡点 / 换素材

视频文件覆盖 `assets/` 同名文件即可；弹幕时间点、商品卡弹出时间、各国商品数据在 `js/config.js`。

- Sony、Fjällräven、adidas、YAMAHA、大众点评、高德等品牌与商品图**仅为植入能力演示示意，非真实商业合作**；价格为示例。页面页脚已注明。
